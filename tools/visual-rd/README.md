# 2026-09-06 映像R&D（PRIVATE_SPEC）

## 比較方法

プロジェクトルートをローカルHTTP配信し、`tools/visual-rd/index.html` を開く。CURRENT / BASELINEと場面を選択。6秒ボタンは固定時刻の比較、打撃ボタンは180ms時点の静止描画。製品画面からリンクしない。ゲームの抽選・保存データとは独立。

`baseline/` の2ファイルは今回のR&D直前にコピーした実装。過去全体のバックアップではない。変更前の比較用に残す。新規ヘルパーは baseline では使わない。

## 発見と採用

- 単位箱をスケールすると加工画像が伸び、部材の大きさによって模様の縮尺が変わる。実寸・面取り付きの共有ジオメトリと物理寸法ベースUVへ変更。
- 単純な固定反射画像はキューブ面の継ぎ目と面全体の単調な映り込みが目立つ。方向から生成した連続的な照明環境と、視線角度による反射へ変更。透明素材は正面の透けと縁の反射を分離。白飛びは素材シェーダーのハイライト肩で抑制。
- 走査・横方向の歪みが追加ディテールを消していた。構造物場面のみ後処理の歪み・走査を抑え、局所的な弱いハレーションを追加。橋本駅の既存後処理強度は維持。WebGL2ではscene targetに2サンプルMSAA。
- 即売会の床の隙間を連続した床へ修正。柱の足元・低い側壁・天井灯を追加。ラウンジにはガラス芯、台座、照明、天井接続材。赤BIG/REGにはガラスリングの金属留め具と細い支持縁。
- 細線をセル単位へ結合。反復部材はセル内InstancedMeshへ集約。開閉するババア臭の扉は独立メッシュを維持。
- 対決時だけ28個の再利用破片、床の短い波紋、敵の接地影を追加。乱数抽選ではなく固定配列と演出時刻による動き。待機/PUSH時は破片を表示しない。

## 確認

- 実ブラウザの変更前後比較：即売会。新しい形状と連続床を目視。
- 赤BIG、青BIG、ブースト、しばくでを比較ページで目視。素材、細線、暗部、透過を確認。最終の破片サイズ・色の微調整は構文確認のみ。
- 実ゲームの通常→しばくでCZ突入を既存操作で確認。コンソールエラーなし。短時間のDOM既存メトリクスは120fps/8.33ms、86 draw callsを示したが、全端末・全場面の性能保証ではない。
- 同一即売会フレームは開始時106 calls、形状追加・細線結合後90 calls。その後さらに部品をまとめ描画。赤BIGは部材追加試作279 calls→まとめ描画後81 calls（約46k triangles）。比較時のシーン条件限定であり総ゲーム負荷の比率ではない。
- 変更JSの構文確認。確率シミュレーション、ゲーム全状態の網羅テストは行わない。

## 変更範囲と保留

`cabinet-surfaces.js`、`cabinet-combat.js` を追加。`cabinet-world.js`、`digital-abstract-scene.js`、`index.html` の描画読み込みを更新。app.js、払出・抽選、リール制御、BGM、操作UI/CSSは変更しない。新しい外部ライブラリや画像生成は使わず既存素材を再利用。

リアルタイム平面反射、SSR、重いブルーム多段パスは未採用。現在の液晶サイズと操作応答に対しコストが大きく、今回の方向反射・軽い局所光で留めた。透明物同士の重なりは従来同様のアルファ合成で、物理的な屈折ではない。
