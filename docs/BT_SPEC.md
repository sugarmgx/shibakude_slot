## 合意した仕様
- 通常時はゾーン・引き戻し・高確なし。天井以外の役別CZ抽選はG数に依存しない。
- 天井は現在G数（BONUS終了後、CZ/BT消化を含む）918G。既存3種類のCZを従来振分けで経由し、赤BIG/青BIGを43:12で保証する。REGは出さない。CZ中に到達した場合は進行中CZに保証を適用する。しばくでは最終PUSH、ババアは挟み目3回のフローを維持。中段チェリーの青4回保証は優先。
- 通常画面は0Gで橋本駅。現在G数50Gごとに他の2ステージから等分に擬似ランダム選択し、同一ステージの連続を避ける。CZ/BT中に跨いだ場合は通常復帰時に反映。ステージ選択は演出専用hashで、当落乱数・確率には影響しない。
- 通常小役分布は旧設定1と同一、設定間共通。
- CZ振分け: うんこ50%、ババア35%、しばくで15%。
- CZ最終成功率: 25% / 45% / 70%。旧版の追加書き換え・昇格・役連続によるAT当選を加算しない。
- うんこ6G、ババア8G（挟み目ごと残G再設定）、しばくで10G＋最終PUSHを維持。
- 通常直撃1/2000、中段チェリー1/16384。優先順位は中段チェリー→直撃→CZ。
- 通常当選BONUS振分け: 赤43%、青12%、REG45%。
- 赤200枚、青280枚、REG80枚、GOLD REG320枚。差枚が規定値を「超えた」ゲームの払出を全額受け取って終了。
- REG連続3回目はGOLD REG。通常・BT経由とも通算。BIGで連続回数を消去。
- GOLDは赤7・赤7・BAR、BIGカウンター加算、終了後は赤BIGと同じBT。連続回数は通常UIに表示しない。
- 中段チェリーは初回を含め青BIG合計4回。残り3回を専用保証として保持し、4回目終了後に青BT。
- 通常Vストック、開米／開開米、玉、上位、引き戻し、エンディングの遊技経路を廃止。

## BTルーレット
ルーレットはレバーで抽選し、第三停止後の精算で結果を適用。
BONUS当選時は同じBTゲームで対応するBONUS図柄を引き込み、そのままBONUSへ移行する。BONUS確定・無料図柄揃えモードは経由しない。当選Gは3BET・払出0枚。非当選Gは通常の小役出目・払出を維持する。
当選時の第一停止で40%の一確演出。非当選かつ内部ハズレ時の35%で7煽りを選択するが、4コマ以内かつ安全な停止候補がある場合のみ1個・2個を停止し、全5ラインの誤BONUS揃いを禁止する。
ハズレ3連続で終了、リトライはカウント0。3灯はハズレで1灯ずつ消灯し、リトライで全点灯。
枚数リザルトの硬直中はルーレットを隠し、終了後に表示する。
ハズレ枠は×。最初の2回は「ハズレ 残り2回→1回」、リトライ時は「RETRY」の3D文字がせり出す。残り0回ではルーレットを消し、既存CZと共通の「失敗」演出・失敗BGMを次SPINまで保持、次SPINでフェードアウト。ハズレ時はbt-miss.wavをSE再生。AUTOはCZ失敗と同じ2秒待機（DEBUG FASTを除く）。
AUTOはPUSH待ちなし。ハズレ・RETRY告知は1.45秒の操作ロックを置く（DEBUG FASTでは短縮）。
