# BT版 UI・液晶演出ブラッシュアップ方針

状態: フェーズ5の基盤とフェーズ3を実装済み。フェーズ1・2・4の残りは未着手。仕様の一次参照は `docs/BT_SPEC.md` と実コード。

## 実装済み(2026-09-29)

### 液晶CG(フェーズ5の基盤)
- `digital-abstract-scene.js`: 表示パスを合成ターゲット(MSAA、対応環境ではHalfFloat)へ描き、3D文字もそこへ重ねる。そのあと5段のブルームと衝撃シェーダーを通して画面へ出す。
  - 衝撃 `impact({strength, hold, color, rays, flash})`: 溜め(暗転と微速ドリーイン)→解放(ホワイトアウト、衝撃波の歪み、色収差、光条、ズームパンチ、揺れ)。
  - 通常時のブルームは弱く、0.9以下の階調は変えない。reduced motion では歪み・揺れ・ズームを切る。
  - 溜めの間は、DOMの液晶文字も `data-impact-hold` で一緒に沈める。
- `cabinet-title.js`: 赤/青BIG確定の瞬間に、リールの7を立体化して差し込む(背後だけを遮光→着地→バネで収まる→カメラを突き抜けて退場し、BIG BONUSの文字へ渡す)。REGでは出さない。色は揃った図柄の色で、表示済みの情報だけを使う。
- `visual-effects.js`: 衝撃の割り当て。BIG確定(最強・光条あり)、1確、CZ勝利、ロングフリーズ(溜め長め)、CZ突入(918G到達時は暗転を長く)、ボーナス結果(弱)。

### メニュー/設定(フェーズ3)と「AI的UI」の払拭
- MENUとDATAを、液晶の上に浮くカードから、液晶そのものに描くサービス画面へ変更した。十字キー・矢印キー・Enter/Space・ESCで操作し、スライドするランプバーと操作音(SE音量とSOUND設定に従う)を付けた。
- 設定は◀▶で候補を選び、決定で反映する(元の select は即リセットだった)。回転中など無効な間は低い音で拒否する。
- DATAは上部カウンターと同じ語彙(CURRENT/BIG/REG)と既存の統計カード、履歴6行の表にした。新しい数値は出していない。
- リセット確認・十字キーのクイック表示も、同じ見た目の言語にそろえた。
- サービスパネルのボタンは、キー面に文字を印字したピル型をやめた。LED窓付きのゴムキーにし、ラベルは筐体面へのシルク印刷として表現する。

### BGA(背景)の強化(2026-09-29 追加)
- `app/lcd-atmosphere.js`: 奥行きの三層を追加した。
  - 遠景: 流れる粒子1.2万。画面の左右に厚く配置し、トンネルの進行方向へ流す。ボーナス中は渦を巻いて奥へ吸い込まれる。
  - 中景: 霧と光の筋(空気中の光として深度テストなし)。
  - 近景: ボケ玉。
- ステージごとの光の設計: 橋本駅は寒色、蛍光灯のちらつき、通過する電車の光。即売会はマゼンタのスポット。ラウンジは暖色。最終段で色味とコントラストを軽くグレーディングする。
- BGM同期: `tools/build-bgm-pulse.cjs` で各曲の低音の推移を事前解析し、`assets/audio/bgm-pulse.js` に保存した。app.js の読み取り専用 `ShibakuMusicClock` から再生位置を引き、キックに合わせて光・粒子・カメラ・ボーナスのリングを脈打たせる。音の経路は変えないので、file:// でもBGMは鳴る。
- 盤面反応: レバーで中心から波紋と粒子の加速、停止ボタンで止まったリール上に光の柱、ベルの払い出しで粒子の閃き。表示済みの操作にだけ反応する。
- ルック修正:
  - 残像の中心への蓄積を抑え、ボーナス中の中心の白飛びを抑えた。
  - ボーナス中は赤い板を薄くした。
  - 「BIG BONUS」は一直線に揃って着地し、一度だけスタンプする。
  - 液晶下端の進捗ラインと四隅のL字線を消した。
  - ベルナビ: 余白をボーナス中は常に確保し、立体文字の位置追従に減衰を入れて、1ゲームごとの上下の跳ねを解消した。

### 液晶の追加演出と筐体の作り直し(2026-09-29 追加)
- 液晶:
  - 光の受け渡し: ブルームの縮小像を左・中央・右で読み取り、`--glow-l/c/r/i` として筐体のサイドランプ、トップランプ、スピーカー縁、リール窓の上辺、床の反射へ流す。
  - 横に伸びるフレア(アナモルフィック)を追加した。
  - 被写界深度: 深度バッファを使い、背景だけを円形にぼかす。
  - ボーナス中は、トンネルの床に映り込みを入れた。
  - 場面転換: 前の場面の最後のフレームを保持し、CZはシャッター、ボーナスはガラス割れ、それ以外は斜めのスラッシュで切り替える。
  - 第3停止: 130msだけ映像を止め、別アングルへハードカットする。次のレバーで元のアングルへ戻る。
  - ステージの見せ場: 橋本駅は柱の奥を電車が通過する。即売会は観客のシルエットがBGMのキックで揺れる。ラウンジはミラーボールの光。
- 筐体(`app/cabinet-shell.js` と `app/cabinet-shell.css`。見た目はここに集約した):
  - 島データカウンターと台を1ユニットとして画面に収め、スクロールをなくした。背景はホールの島の光。
  - 質感はテクスチャで出す(`tools/build-cabinet-textures.cjs`): ヘアライン金属、樹脂の粒子感、スピーカーの網目、ホールの背景。
  - 部位を実機の構成にした。トップランプ、左右のサイドランプ(液晶と連動)、リール両脇のスピーカー、配当表を印刷した腰部パネル。
  - 操作部: 停止ボタンは有効時に青いLEDリングが光る。PUSHはデッキ中央の大型ドーム。レバーは戻りで2回揺れ戻してから止まる。MAX BETはデッキへ移した。
  - 配当表(承認済み): BIG(赤7揃い、青7揃い)、REG(赤7・赤7・BAR)、スイカ5枚、ベル3枚、リプレイ。3枚掛け。チェリーは弱と強で払い出しが違うため載せていない。
  - 筐体を縮小して表示するため、立体文字の位置計算を縮小前の座標に換算するようにした。

### 予告・発展・BT(AT)演出(2026-09-29 追加)
- 筐体の「BT」表記を削除した(トップランプ、腰部パネル、旧ロゴ)。本機はAT擬似ボーナス機として扱う。
- 予告(ユーザー承認済み。期待度と連動する): レバー時点で確定済みの結果を、app.js が読み取り専用の `noticeCue` として表示層へ渡す。見た目は表示専用の乱数(xorshift)で選び、抽選の乱数は消費しない。
  - 橋本駅: 電車。普通・急行(赤帯、速い)・金(確定)の3種類。右から奥→手前、左から手前→奥を半々で選ぶ。
  - 即売会・ラウンジ: カメラが前へ突き進んで戻る「移動予告」。金は金色の衝撃が付く。
  - 発生率(PRIVATE_SPEC): 当選60%、CZ45%、強レア14%、弱レア7%、その他3%。金はCZと当選のみ。
  - 時間経過で自動的に走る電車は廃止した(予告の意味を保つため)。
- CZ突入「発展」(1.45〜1.6秒、操作ロック1.85秒): カメラが加速しながら前へ進み、暗転する。立体の「発展」がカメラへ飛び込んで着地し、ガラス割れでCZへ入る。918G到達時は溜めを長くする。DEBUG FAST では省略する。
- ステージ移動(50G): 前のステージを突き抜ける移動ワイプのあと、カメラが奥から入って新しいステージに到着する。
- BT中のルーレット: 20面の回転ドラム(CSS 3D)にした。止まるときは行き過ぎてから戻る。
- BIG中: 規定枚数の半分でカメラが大きく旋回する。85%以降はトンネルを加速する。
- ボーナス終了: 枚数を9段階で数え上げ、最後に確定の衝撃を入れる。カメラはトンネルの外へ引いていく。
- 部屋やCZの場面ではカメラを cabinet-world.js が毎フレーム設定するので、カメラ演出はその後に適用する。

### 通常ステージの作り直し(案C、2026-09-29 追加)
- 方針: 今は案C(リアルタイムで作り込む)で進め、あとから事前レンダリングの映像を重ねる。
- `app/stage-kit.js`:
  - 橋本駅: 抽象的な鉄骨の枠を、島式ホームに置き換えた。
    - 床と点字ブロック、白線、ホームの縁、両側の線路(バラスト、枕木、レール)、タイル壁と照明付き広告
    - コンクリートの柱と鋼製の角当て、天井ルーバー、梁、蛍光灯の二列、吊り下げの駅名標、ベンチ、自販機
    - 18単位で繰り返す一続きの形状を周期的にずらして、無限に続くホームに見せる。繰り返しの部品はインスタンス描画にした。
  - 即売会: カーペット、ブースの机と卓布、頒布物、ポスタースタンド、吊り下げバナーを追加した。
  - ラウンジ: 木の床、ベルベットのソファ、大理石のテーブル、キャンドル、真鍮の酒棚と瓶、ペンダントライトを追加した。

- 素材: `tools/build-stage-textures.cjs` で生成し、`assets/textures/stage/stage-textures.js` と `assets/environment/stage-hdri.js` に埋め込んだ(WebGLはfile://の画像を使えないため)。

  - Poly Haven と ambientCG への直接接続は、この環境のネットワーク設定で拒否された。許可すれば、あとから本物のPBR素材に差し替えられる。
- 電車の予告は、ホーム両側の線路上を走る。
- 修正: BT中のルーレットが「着地」アニメーションに上書きされて回らない不具合を直した。
- 変更: 第3停止の別アングルへの切り替えを廃止した。一瞬の静止だけ残し、カメラワークは途切れない。

### 通常ステージの写実化(2026-09-29 追加)
- テクスチャのコントラストを下げ、大判にした。床は目地の細い磨きテラゾー、壁は琺瑯パネル、柱は平滑な打ち放しコンクリート。
- ステージの材質シェーダーに次を追加した(`StageKit.photoreal`)。
  - 照明の列(駅は蛍光灯4列、即売会は天井3列、ラウンジはペンダント2列)からの光の広がりを計算する。床に光だまりができ、柱や壁の明るさが高さで変わる。
  - 磨かれた床と大理石には、照明の列を映り込ませる。駅では蛍光灯の区切りも映る。
  - 床と壁の境目に足元の汚れを入れ、大きな色ムラと粗さのムラで繰り返し模様を崩した。
- 駅では、全体を一様に照らす既存のライト(空の光、キーライト、リムライト)を弱めた。
- 画面の最終合成に、ごく弱いフィルム粒子を加えた。
- Poly Haven と ambientCG への接続は、現在も拒否されている。

### 最適化と通常ステージのカメラ(2026-09-29 追加)
- 引っかかりの対策:
  - 第3停止での静止(130ms)を廃止した。
  - 筐体のランプ用の色の読み戻しを、非同期にした(WebGL2 のピクセルパックバッファとフェンス)。GPUの完了待ちで描画が止まらない。
  - 起動後とステージ用HDRIの読み込み後に、全ステージ・全場面のシェーダー作成とテクスチャ転送を事前に行う。起動後は、場面を切り替えても新しいシェーダーを作らない(実測で123個のまま)。
  - 立体文字は1文字ずつキャッシュする。リザルトの数え上げで、数字を作り直さない。
  - 描画が重い端末では、描画解像度を0.25刻みで1.0まで下げる。それでも重ければ、被写界深度と床の映り込みを切る。
- 通常時は、24秒周期の抽象レイヤーの乱れ(崩れの場面)を止め、落ち着いた状態で固定した。抽象レイヤーは、写実ステージのある通常時には表示しない。
- 通常ステージのカメラ: ステージごとに5アングルを用意し、壁時計で15秒ごとに切り替える。レバーやボタンの操作とは無関係で、各アングルは15秒かけてゆっくり移動する。予告の突進や発展のカメラ演出は、この上に重ねる。

### カメラの物体貫通の修正(2026-09-29 追加)
- 原因1: 駅のホームを、通常時も周期的にずらし続けていたため、柱や駅名標がカメラの位置へ流れてきた。通常時はホームを止め、突進中だけ流すようにした。突進のあとは、次の周期の位置(配置が同一になる位置)まで送ってから止める。
- 原因2: アングルの位置が柱、ガラス柱、ポスター、線路上の電車に近すぎた。7アングルの位置を調整した。
- `tools/check-camera-clearance.cjs`: 全アングルについて、15秒の移動の経路と前方26単位の突進の経路を、ステージの全物体(インスタンス1つずつを含む)の外形と照合する。余白は0.12。現在は3ステージとも接触0件。

## 守る制約(AGENTS.md より)

- 新規の表示文言は追加しない。内部状態は光・色・暗転・間・SE・リール挙動で表す。
- REG連続回数、青BIG保証残数、BT抽選表はPRIVATE_SPECのまま。通常UIとデバッグ表示に出さない。
- 918G天井→CZ→赤/青BIG保証以外に、旧天井・ゾーン・高確・AT・玉・Vストック・引き戻しを復活させない。
- 抽選・確率・リール制御ロジックは変更しない。見た目と挙動の演出層だけを触る。
- `app/app.js` の抽選と状態遷移には手を入れない。

## フェーズ計画

### フェーズ1: 筐体の質感
- ベゼルの金属感(グラデーションとハイライト)、リール窓のガラス反射・内側の影、リール周辺のバックライト光漏れ。
- 各ランプとLEDの発光を、色温度とにじみ(glow)で統一する。
- 状態ごとに光の強さを変え、常時の視覚ノイズは増やさない。

### フェーズ2: リール挙動と停止ボタン
- 始動時の加速カーブ、回転中の残像ブラー、停止時のわずかなバウンド。
- 停止ボタンは押し込み量、点灯、押下後の余韻を実機寄りにする。
- 押下から停止までの遅延感を損なわない。既存の停止制御の結果は変えない。
- タッチ端末では振動(対応端末のみ)と、押下時のフィードバックを付ける。

### フェーズ3: メニュー/設定操作
- 設定セレクトを、実機の設定キー/操作パネル風の表現に置き換える。
- 開閉のアニメーション、選択時のクリック感、フォーカス表示を整える。
- 新しいラベルは増やさない。既存の語彙のまま操作感だけを変える。

### フェーズ4: 液晶演出の共通言語
- 「溜め→間→解放」の3拍構成に統一する。
  - 溜め: 暗転、光の収束、SEの低音。
  - 間: 一瞬の無音か静止。
  - 解放: 図柄の確定、閃光、リールとランプの同期。
- 各場面への適用:
  - 赤/青BIG確定: 色で赤と青を区別し、段階的に盛り上げる。
  - CZ突入: 溜めを長めにし、リーチ目との同期を強める。
  - 918G天井: 到達の重みを、暗転と間で表現する。
  - 予告とリーチ目の煽り: 段階を刻んで期待を高める。
  - BIG中とBT終了: 盛り上がりと余韻を作る。
- 軽量化: WebGL/Canvasの負荷を確認し、低性能端末では自動で演出を簡略化する。

### フェーズ5: 液晶CG(three.js/GLSL)の見応え強化

現状: `digital-abstract-scene.js` は unlit なライン・粒子・板とフィードバック残像が主体。`visual-effects.js` の7図柄は BoxGeometry の組み合わせ。主役の立体と、光と材質による奥行きがない。

1. 主役オブジェクト: 赤7と青7を面取りした押し出しジオメトリにし、金属と発光のPBR材質にする。環境マップは既存HDRI(`assets/environment`、`cabinet-hdri.js`)を流用する。
2. HDRとブルーム: HDRレンダーターゲットで発光部だけを1.0超えにし、ブルームとACESトーンマッピングをかける。
3. カメラワーク: 溜め(ドリーイン)→間(静止)→解放(速いズームと揺れ)。被写界深度で主役を立てる。
4. 奥行きの三層: 既存の抽象レイヤーを遠景にし、中景に光の筋と霧、近景に破片と火花を置く。
5. 確定の瞬間専用のシェーダー: 放射状の衝撃波歪み、色収差の瞬間強調、ホワイトアウトからの色戻り。
6. 性能: 中程度のPCで60fpsを維持する。pixelRatio の上限を固定する。

進め方: 赤/青BIG確定の1場面で試作して質感基準を決め、CZ突入、918G天井、予告、BIG中へ横展開する。キャラクターやモデルの新規アセットは対象外。

## 演出強化(予告・CZ・ルーレット・BONUS中・SE)の実装メモ

- 予告(`app/lcd-notice.js`): レバー時の確定結果から、演出専用の乱数で種類と色を選ぶ(抽選用の乱数は使わない)。
  - ステップアップ: レバー→第1→第2→第3停止で段階が上がる。橋本駅では蛍光灯のちらつき→発車標→警報灯→電車。
  - 色の格付け: 白<青<黄<緑<赤<金<虹。電車の帯、発車標、筐体ランプ、PUSHドームで共通。
  - 発車標: 駅の掲示物として種別(普通〜臨時)を出す。
  - PUSHボタン: ドームが光り、押す(またはEnter)と色が出る。押さなくても第3停止で自動で出る。
  - 消灯: レバーで液晶と筐体ランプが消え、第3停止で色付きで復帰。
  - プレミア: 当選時のごく一部で虹色(電車・ランプ・液晶)。
- CZ: 残り3G以下で段階的に強まり、最終Gは暗転と揺れ(`cz-final`)。
- しばくでチャレンジ: 最終G後に溜め(pushCharge)→決定音と同時にPUSH。異常PUSH(巨大/赤)は勝利濃厚。溜め中はPUSHを受け付けない。
- PUSH前の溜め: 中心から外へ広がる無限の同心円が加速する(Canvas)。
- 「※貫通した」プレート: 勝利時の20%でPUSHの代わりに `assets/images/kankutsu.png` を大きく出し、必ず `pushKankutsu.mp3`(成功音)を鳴らす。
- REG BONUS中は液晶に `assets/video/reg-movie.mp4` を無音ループで流す(BGMはそのまま)。
- REG映像はGOLD REGでも流す。映像の上にBGMのキックに合わせた白フラッシュと縁の発光を重ね、獲得枚数は変わるたびに弾む。
- リールフラッシュ: 通常時の当選(消灯/1リール点灯/点滅)とCZ突入(点滅)、ボーナス開始(ファンファーレ)で、リールのバックライトを光らせる。
- 筐体ランプ: BONUS/BT/AT中はBGMのキックに合わせて明滅。ボーナス開始時は虹色で流れる。
- 無音の間: 通常時の当選、しばくでのPUSH後、ババア臭3回目の挟み目で、確定の直前に約0.35秒すべての音を止めて液晶を落とす。
- 逆回転フリーズ(プレミア): 通常時当選の3%で、暗転中にリールが逆回転して7が中段に揃い、そこから通常の回転に入る。
- ガラス割れ: ババア臭3回目の明けと天井CZ突入でも割る。
- うんこ6ゲーム: ゲームが進むほど色が暖色へ寄り強まる。最終ゲームの当選は40%で、ヒビ→粉砕の逆転を経て確定する。
- しばくでの敵: パンチの大小でのけぞり方が変わり、勝ちを保持している間はよろける。
- レバーオン無音: レバー時に回転音を鳴らさない予告。当選・CZほど出やすい。
- 第3停止ディレイ: 期待度が高いと、第3停止ボタンを押してからリールが止まるまで約0.3秒遅れる。
- 全回転(最上位プレミア): 通常時当選の1%で、全リールが7だけで高速回転し、7が中段に揃ってから通常の回転に入る。逆回転フリーズより優先。
- 同人音楽即売会の予告: ブースの手書きPOP「新譜CD 頒布数」。0枚→10枚→30枚→100枚→1000枚→完売(金)→増刷決定(虹)。数字は回ってから止まり、熱いほど観客が跳ねる。
- クラブのラウンジの予告: LEDテロップの床アナウンス。異常なし→きしみ→1cm→5cm→10cm→抜けそう(金)→抜けました(虹)。沈むほどカメラが下がり揺れる。
- どちらも橋本駅の発車標と同じ枠(掲示予告/ステップアップの中身)で、色の格付けと抽選は共通。
- ガラス: `app/lcd-glass.js` のCanvasでヒビと破片を描く。失敗はヒビで止まり、復活はヒビ→粉砕(glassBreak2)→勝利。
- ババア臭チャレンジ3回目: ブラックアウト後に液晶を切り替え、「BONUS確定」の登場が見えるようにした。
- BT: 7付近での減速・滑り込み・行き過ぎ戻り。残り1灯で色を落とし心音の脈動。
- BONUS中: BGMの拍を推定し、2小節ごとのキックでカメラを切り替える。
- SE(`app/lcd-sound.js`): `assets/audio/fx/<名前>.mp3` があればそれを、無ければWebAudio合成音を鳴らす。`xxxHot` はファイルが無ければ通常版のファイルを使う。
