# BT版 UI・液晶演出ブラッシュアップ方針

状態: フェーズ5の基盤とフェーズ3を実装済み。フェーズ1・2・4の残りは未着手。仕様の一次参照は `docs/BT_SPEC.md` と実コード。

## 実装済み(2026-09-29)

### 液晶CG(フェーズ5の基盤)
- `digital-abstract-scene.js`: 表示パスを合成ターゲット(MSAA、対応環境ではHalfFloat)へ描き、3D文字もそこへ重ねる。そのあと5段のブルームと衝撃シェーダーを通して画面へ出す。
  - 衝撃 `impact({strength, hold, color, rays, flash})`: 溜め(暗転と微速ドリーイン)→解放(ホワイトアウト、衝撃波の歪み、色収差、光条、ズームパンチ、揺れ)。
  - 通常時のブルームは弱く、0.9以下の階調は変えない。reduced motion では歪み・揺れ・ズームを切る。
  - 溜めの間は、DOMの液晶文字も `data-impact-hold` で一緒に沈める。
- `cabinet-title.js`: 赤/青BIG確定の瞬間に、リールの7を立体化して差し込む(背後だけを遮光→着地→バネで収まる→カメラを突き抜けて退場し、BIG BONUSの文字へ渡す)。REGでは出さない。色は揃った図柄の色で、表示済みの情報だけを使う。
- `visual-effects.js`: 衝撃の割り当て。BIG確定(最強・光条あり)、1確、CZ勝利、ロングフリーズ(溜め長め)、CZ突入(918G到達時は暗転を長く)、ボーナス結果(弱)。

### メニュー/設定(フェーズ3)と「AI的UI」の払拭
- MENUとDATAを、液晶の上に浮くカードから、液晶そのものに描くサービス画面へ変更した。十字キー・矢印キー・Enter/Space・ESCで操作し、スライドするランプバーと操作音(SE音量とSOUND設定に従う)を付けた。
- 設定は◀▶で候補を選び、決定で反映する(元の select は即リセットだった)。回転中など無効な間は低い音で拒否する。
- DATAは上部カウンターと同じ語彙(CURRENT/BIG/REG)と既存の統計カード、履歴6行の表にした。新しい数値は出していない。
- リセット確認・十字キーのクイック表示も、同じ見た目の言語にそろえた。
- サービスパネルのボタンは、キー面に文字を印字したピル型をやめた。LED窓付きのゴムキーにし、ラベルは筐体面へのシルク印刷として表現する。

### BGA(背景)の強化(2026-09-29 追加)
- `app/lcd-atmosphere.js`: 奥行きの三層を追加した。
  - 遠景: 流れる粒子1.2万。画面の左右に厚く配置し、トンネルの進行方向へ流す。ボーナス中は渦を巻いて奥へ吸い込まれる。
  - 中景: 霧と光の筋(空気中の光として深度テストなし)。
  - 近景: ボケ玉。
- ステージごとの光の設計: 橋本駅は寒色、蛍光灯のちらつき、通過する電車の光。即売会はマゼンタのスポット。ラウンジは暖色。最終段で色味とコントラストを軽くグレーディングする。
- BGM同期: `tools/build-bgm-pulse.cjs` で各曲の低音の推移を事前解析し、`assets/audio/bgm-pulse.js` に保存した。app.js の読み取り専用 `ShibakuMusicClock` から再生位置を引き、キックに合わせて光・粒子・カメラ・ボーナスのリングを脈打たせる。音の経路は変えないので、file:// でもBGMは鳴る。
- 盤面反応: レバーで中心から波紋と粒子の加速、停止ボタンで止まったリール上に光の柱、ベルの払い出しで粒子の閃き。表示済みの操作にだけ反応する。
- ルック修正:
  - 残像の中心への蓄積を抑え、ボーナス中の中心の白飛びを抑えた。
  - ボーナス中は赤い板を薄くした。
  - 「BIG BONUS」は一直線に揃って着地し、一度だけスタンプする。
  - 液晶下端の進捗ラインと四隅のL字線を消した。
  - ベルナビ: 余白をボーナス中は常に確保し、立体文字の位置追従に減衰を入れて、1ゲームごとの上下の跳ねを解消した。

## 合意した方向性

| 項目 | 決定 |
|---|---|
| 最優先 | 実機らしく触りたくなるUIと、当たる瞬間が気持ちいい液晶演出 |
| 筐体の質感 | 実機筐体リアル寄り。装飾の量より、光と影の密度を上げる |
| 操作感の重点 | リール回転・停止挙動、メニュー/設定操作 |
| 液晶演出 | 全体に均等に質感アップ(BIG確定・CZ・918G天井・予告・BIG中・BT終了) |
| 進め方 | 方針を先に文書化し、承認後に段階実装 |
| 対象環境 | PC横画面のみ |
| 液晶CG | 抽象デジタル路線を維持し、立体の主役と光の質を足す |

## 守る制約(AGENTS.md より)

- 新規の表示文言は追加しない。内部状態は光・色・暗転・間・SE・リール挙動で表す。
- REG連続回数、青BIG保証残数、BT抽選表はPRIVATE_SPECのまま。通常UIとデバッグ表示に出さない。
- 918G天井→CZ→赤/青BIG保証以外に、旧天井・ゾーン・高確・AT・玉・Vストック・引き戻しを復活させない。
- 抽選・確率・リール制御ロジックは変更しない。見た目と挙動の演出層だけを触る。
- `app/app.js` の抽選と状態遷移には手を入れない。

## 現状の把握

- `app/app.js`(4,602行)はロジックとUI制御が混在する。リールのアニメーションは `requestAnimationFrame` ベース。
- 筐体は `cabinet-*.js` と `cabinet-*.css`、液晶は `visual-effects.js` と `digital-abstract-scene.js`、BT表示は `bt-presentation.js` と `bt.css` が担う。

- 既存のテストは `tests/` 配下(reel-control, cz-presentation など)。

## フェーズ計画

### フェーズ1: 筐体の質感
- ベゼルの金属感(グラデーションとハイライト)、リール窓のガラス反射・内側の影、リール周辺のバックライト光漏れ。
- 各ランプとLEDの発光を、色温度とにじみ(glow)で統一する。
- 状態ごとに光の強さを変え、常時の視覚ノイズは増やさない。

### フェーズ2: リール挙動と停止ボタン
- 始動時の加速カーブ、回転中の残像ブラー、停止時のわずかなバウンド。
- 停止ボタンは押し込み量、点灯、押下後の余韻を実機寄りにする。
- 押下から停止までの遅延感を損なわない。既存の停止制御の結果は変えない。
- タッチ端末では振動(対応端末のみ)と、押下時のフィードバックを付ける。

### フェーズ3: メニュー/設定操作
- 設定セレクトを、実機の設定キー/操作パネル風の表現に置き換える。
- 開閉のアニメーション、選択時のクリック感、フォーカス表示を整える。
- 新しいラベルは増やさない。既存の語彙のまま操作感だけを変える。

### フェーズ4: 液晶演出の共通言語
- 「溜め→間→解放」の3拍構成に統一する。
  - 溜め: 暗転、光の収束、SEの低音。
  - 間: 一瞬の無音か静止。
  - 解放: 図柄の確定、閃光、リールとランプの同期。
- 各場面への適用:
  - 赤/青BIG確定: 色で赤と青を区別し、段階的に盛り上げる。
  - CZ突入: 溜めを長めにし、リーチ目との同期を強める。
  - 918G天井: 到達の重みを、暗転と間で表現する。
  - 予告とリーチ目の煽り: 段階を刻んで期待を高める。
  - BIG中とBT終了: 盛り上がりと余韻を作る。
- 軽量化: WebGL/Canvasの負荷を確認し、低性能端末では自動で演出を簡略化する。

### フェーズ5: 液晶CG(three.js/GLSL)の見応え強化

現状: `digital-abstract-scene.js` は unlit なライン・粒子・板とフィードバック残像が主体。`visual-effects.js` の7図柄は BoxGeometry の組み合わせ。主役の立体と、光と材質による奥行きがない。

1. 主役オブジェクト: 赤7と青7を面取りした押し出しジオメトリにし、金属と発光のPBR材質にする。環境マップは既存HDRI(`assets/environment`、`cabinet-hdri.js`)を流用する。
2. HDRとブルーム: HDRレンダーターゲットで発光部だけを1.0超えにし、ブルームとACESトーンマッピングをかける。
3. カメラワーク: 溜め(ドリーイン)→間(静止)→解放(速いズームと揺れ)。被写界深度で主役を立てる。
4. 奥行きの三層: 既存の抽象レイヤーを遠景にし、中景に光の筋と霧、近景に破片と火花を置く。
5. 確定の瞬間専用のシェーダー: 放射状の衝撃波歪み、色収差の瞬間強調、ホワイトアウトからの色戻り。
6. 性能: 中程度のPCで60fpsを維持する。pixelRatio の上限を固定する。

進め方: 赤/青BIG確定の1場面で試作して質感基準を決め、CZ突入、918G天井、予告、BIG中へ横展開する。キャラクターやモデルの新規アセットは対象外。
